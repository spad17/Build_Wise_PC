# Build Wise PC

Rails-приложение для подбора и сохранения сборок компьютера: регистрация, вход, cookie-сессия, конфигуратор, каталог, отзывы и личный раздел.

## Запуск

Требования: Ruby 3.2+ (для Rails 8 нужен Ruby 3.2 или новее) и Bundler.

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

Откройте `http://localhost:3000`.

## Демонстрационная база данных

В репозитории находится `db/demo.sqlite3`: отдельный снимок SQLite со схемой, индексами, внешними ключами и каталогом комплектующих. Откройте его в DBeaver или DB Browser for SQLite для просмотра таблиц и ER-диаграммы. Пользовательские аккаунты, сборки и отзывы в снимок не включены.

Рабочая база `db/development.sqlite3`, тестовая база и служебные файлы SQLite (`-wal`, `-shm`) остаются в `.gitignore`. Приложение продолжает использовать рабочую базу; демонстрационный снимок не обновляется автоматически. Исходная схема хранится в `db/schema.rb`, история изменений — в `db/migrate`.

## Ручная проверка

1. Нажмите «Регистрация», заполните имя, email, пароль и подтверждение. После сохранения откроется главная страница с вашим именем.
2. Обновите страницу и перейдите в «Мои сборки»: сессия сохраняется, раздел открывается.
3. Нажмите «Выйти»: шапка снова показывает «Войти» и «Регистрация», а «Мои сборки» перенаправляет на страницу входа.
4. Войдите повторно с email и паролем. Неверный пароль показывается как ошибка без создания сессии.
5. Повторная регистрация с тем же email в другом регистре отклоняется.

## Тесты

```bash

```

Тесты покрывают регистрацию, уникальность email без учёта регистра, хеширование паролей, вход, сохранение сессии, выход, шапку и защиту закрытого раздела.

## Конфигуратор и happy path

1. На главной нажмите «Начать сборку». Войдите или зарегистрируйтесь: после этого откроется форма подбора.
2. Выберите x64 или Threadripper, задачу и бюджет от 10 000 до 5 000 000 рублей. E2K представлен реальными изделиями МЦСТ по запросу поставщику; автоматический подбор не обещает непроверенную совместимость.
3. При желании укажите «32 ГБ ОЗУ, SSD 1 ТБ, тихий». Объёмы распознаются как обязательные минимумы, тишина повышает оценку тихих деталей. Произвольный остальной текст сохраняется как заметка; языковой модели здесь нет.
4. Нажмите «Подобрать и сохранить ПК». Восемь компонентов появятся в сохранённой сборке; видны стоимость и остаток бюджета.
5. Нажмите название детали: откроется окно характеристик и отзывов. Зарегистрированный пользователь может добавить, изменить или удалить свой отзыв (один на деталь).
6. Нажмите «Выбрать замену», отфильтруйте каталог, выберите деталь. Сервер проверит бюджет, пожелания и совместимость, остальные позиции сохранятся.
7. Отметьте «Оставить неизменным» у нужных деталей и нажмите «Пересобрать ПК». Для обязательной замены всех остальных включите соответствующий флажок. Если решения нет, исходная сборка сохранится целиком.
8. Обновите страницу или войдите заново: сборка останется в «Моих сборках». Доступны печать/PDF через браузер и удаление сборки.

## Алгоритм

`app/services/build_optimizer.rb` решает multiple-choice knapsack (задачу о рюкзаке с группами) методом branch-and-bound: ровно одна деталь каждой из восьми категорий, сумма цен не выше бюджета. Цель — максимальная сумма условных баллов производительности с весами под задачу; при равенстве выбирается более дешёвый набор. Фиксированные детали образуют группы из одного элемента. Можно исключить прежние незакреплённые варианты.

При поиске отсекаются ветви по минимальной оставшейся цене и максимально возможной оценке. Проверяются платформа, сокеты, тип памяти; охлаждение должно отводить мощность CPU, БП — покрывать суммарное потребление с запасом 25%. Правила `CompatibilityRule` сохраняют ранее реализованную семантику явного разрешения совместимости пары. Доступ к сохранённым сборкам и изменениям отзывов ограничен владельцем. Обновление набора выполняется в транзакции.

## Данные и ограничения

`db:seed` идемпотентно импортирует 37 **реальных моделей** из `db/catalog.rb`: Intel Core, AMD Ryzen/Threadripper, ASUS PRIME/TUF/Pro WS, SAPPHIRE Radeon, GeForce RTX от ASUS/MSI, Kingston FURY/A400/KC3000, Corsair, DeepCool, Noctua, Cooler Master, Fractal Design и МЦСТ. В каждой записи сохранена ссылка на официальный источник и дата сверки 30.10.2026. Ссылки доступны в окне характеристик. Цены в рублях — редакционные ориентиры для расчёта, не текущие предложения магазинов; баллы подбора относительные, не результаты бенчмарков. Наличие в магазинах не отслеживается. Старые записи Build Wise Demo выводятся из подбора (`available: false`), а существующие сборки и отзывы сохраняются. Сборку из заглушек можно пересобрать на реальных деталях.

Проверяются сокеты, несколько креплений одного кулера, DDR4/DDR5/DDR5 RDIMM, число модулей и лимит ОЗУ платы, форм-фактор платы, высота кулера, длина GPU/БП, число EPS-разъёмов и рекомендованная мощность БП от производителя GPU. Лимиты мощности CPU для расчёта консервативные, это не измеренное энергопотребление. Для Noctua NH-U14S TR5-SP6 использован официальный список совместимых CPU; NSPR не выдаётся за ватты. Перед покупкой отдельно уточняются BIOS, QVL, кабели/адаптеры и фактическая комплектация. Модули Kingston продаются комплектами, количество модулей учитывается внутри одной позиции сборки.

Для E2K импортированы МЦСТ Эльбрус-8СВ и модуль 1Э8СВ-uATX, с ценой/комплектацией по запросу. Модуль уже включает процессор. Для этой архитектуры не создаются вымышленные кулеры и не заявляется поддержка произвольных RTX/Radeon: до подтверждения комплекта поставщиком автоподбор возвращает объяснение. x64 и Threadripper проходят полный сквозной сценарий.

10 000 рублей — допустимый нижний бюджет, не обещание полноценной сборки из новых реальных комплектующих за эту сумму. При недостаточном бюджете выводится объяснение; верхний бюджет не обязан расходоваться целиком. Полный перебор с отсечениями рассчитан на небольшой каталог; для большого каталога потребуется более масштабируемый решатель.

Новые тесты проверяют сквозной сценарий, все архитектуры, границы бюджета, пожелания, фиксацию, несовместимые варианты, сохранность сборки при неудаче, владение сборками/отзывами и экранирование отзывов. Оптимальность поиска дополнительно сравнивается с полным перебором небольшого набора.
