# Build Wise PC

Небольшое Rails-приложение для сохранения сборок компьютера. В проекте реализованы регистрация, вход, cookie-сессия пользователя и закрытый раздел «Мои сборки».

## Запуск

Требования: Ruby 3.2+ (для Rails 8 нужен Ruby 3.2 или новее) и Bundler.

```bash
bundle install
bin/rails db:prepare
bin/rails server
```

Откройте `http://localhost:3000`.

## Ручная проверка

1. Нажмите «Регистрация», заполните имя, email, пароль и подтверждение. После сохранения откроется главная страница с вашим именем.
2. Обновите страницу и перейдите в «Мои сборки»: сессия сохраняется, раздел открывается.
3. Нажмите «Выйти»: шапка снова показывает «Войти» и «Регистрация», а «Мои сборки» перенаправляет на страницу входа.
4. Войдите повторно с email и паролем. Неверный пароль показывается как ошибка без создания сессии.
5. Повторная регистрация с тем же email в другом регистре отклоняется.

## Тесты

```bash
bin/rails db:test:prepare
bin/rails test
```

Тесты покрывают регистрацию, уникальность email без учёта регистра, хеширование паролей, вход, сохранение сессии, выход, шапку и защиту закрытого раздела.
